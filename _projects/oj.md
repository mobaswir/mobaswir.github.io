### Features
<ul>
<li>Contest creator can create contests and set problems based on difficulties and categories.</li>
<li>Tutorials and blogs and comments.</li>
<li>Contestants can participate in contests.</li>
<li>Can upsolve problems from previous contests.</li>
</ul>

### Used Stack
- Oracle database.
- ExpressJS for server.
- Frontend built with ReactJS.
